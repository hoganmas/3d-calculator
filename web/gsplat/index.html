web/gsplat

Kerbl-style sorted splat compositing in a Web Worker. Drag to orbit, scroll to zoom, right-drag / shift-drag to pan. Tunable T < ε early-out.

Probes isolate cost: probeBeer = same hard-capped window as approx but Beer T (no Appendix-A) — splits window tax vs Φ tax; probeLog = only −log; probeWin = window without −log; probe = uncapped window + −log + α-T.

Approx / window probes: Appendix-A on a hard-capped window of ≤N overlapping fronts (oldest overflow → Beer). 0 = unlimited.

Keep fronts in the Φ window while |Δμ| ≤ k (σᵢ+σⱼ); else evict → Beer. Larger k = bigger windows (smoother, slower).

LUT: f(x)=−log(1−e^{−x}), x=½r²+(−ln o); −ln o precomputed per splat. Fast: analytic piecewise. Exact: gauss exp + Math.log.
